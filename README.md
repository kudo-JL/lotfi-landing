# JL Landing Page

## إضافة مشروع جديد

افتح `index.html` وانسخ قالب `.project-card` وعبّي البيانات.

## النشر

- **GitHub Pages**: ادفع لـ GitHub، فعّل Pages من Settings
- **Netlify**: اسحب المجلد على app.netlify.com/drop
- **Cloudflare Pages**: Connect to Git من pages.cloudflare.com
- **Vercel**: شغّل `vercel` في المجلد
